Gatitos y Peces - versión web separada

Archivos:
- index.html: estructura del juego y carga de Firebase.
- style.css: estilos visuales.
- game.js: lógica completa del juego.

Para probar en local:
- Puedes abrir index.html directamente.
- Si el navegador bloquea algo, usa una extensión tipo Live Server o ejecuta un servidor local.

Para subir a GitHub Pages:
1. Sube index.html, style.css y game.js a la raíz del repositorio.
2. Activa Settings > Pages > Deploy from a branch > main > /root.
3. El ranking seguirá guardándose en Firebase, no en GitHub.
